# مُحاضِر

**مُحاضِر** هو تطبيق هاتف عربي للطلاب ينظم التسجيلات الجامعية في مسار أكاديمي واضح: السنة الدراسية، ثم الترم، ثم المادة، ثم القسم النظري أو العملي. يسجل الطالب المحاضرة محلياً، ويستطيع عند اختياره تحويلها إلى نص وإنشاء ملخص منظم يساعده في المراجعة.

## ما الذي تم بناؤه؟

| المجال | الوظائف المتاحة |
|---|---|
| تنظيم الدراسة | إنشاء السنوات الدراسية، وإنشاء الترم الأول أو الثاني، وإضافة المواد داخل كل ترم. |
| المواد والمدرسون | دعم مادة نظرية فقط أو مادة ذات قسم عملي، مع تحديد مدرس النظري ومدرس العملي بشكل منفصل أو متطابق. |
| التسجيل | اختيار السنة والترم والمادة والقسم قبل التسجيل، ثم حفظ ملف المحاضرة محلياً بعنوان قابل للتعديل. |
| المحاضرة | تشغيل التسجيل، إظهار حالة التحويل، عرض النص، وإنشاء ملخص منظم. |
| الذكاء الاصطناعي | تحويل الصوت إلى نص عربي عند الطلب، ثم توليد نظرة عامة ونقاط رئيسية ومصطلحات وأسئلة مراجعة. |
| المراجعة | بطاقات مراجعة مستخرجة من أسئلة الملخص، مع تأجيل ذكي للمراجعة التالية وربط مقاطع النص بموضعها الصوتي. |
| التخزين والتصدير | شاشة لحجم الملفات المعروف، حذف المحاضرات محلياً، وتصدير النص والملخص إلى PDF عبر لوحة المشاركة. |
| المرفقات | التقاط صورة للسبورة، اختيار صورة، أو إرفاق PDF/Word، مع بقاء المرفقات ضمن المحاضرة على الجهاز. |
| الخطة والتنبيهات | واجبات واختبارات ومراجعات بتذكيرات محلية وإجراء اختياري لإضافتها إلى تقويم الهاتف. |
| النسخ الاحتياطي | نسخة اختيارية بعد تسجيل الدخول لحفظ هيكل الدراسة والنصوص والملخصات واستعادتها على جهاز آخر. |

## تجربة الاستخدام

ينشئ الطالب سنة مثل «2026–2027»، ثم يفتح الترم الأول أو الثاني ويضيف المواد. عند تعريف مادة عملية تظهر لها وجهتا حفظ: **نظري** و**عملي**. قبل التسجيل يختار الطالب وجهة الحفظ، فيمنع ذلك تشتت التسجيلات بين المواد أو الأقسام.

بعد إيقاف التسجيل، يحفظ الطالب المحاضرة محلياً. من صفحة المحاضرة يستطيع تشغيل الصوت، ثم يختار «تحويل إلى نص». عند ظهور النص، يمكنه إنشاء الملخص الذكي. لا يبدأ التطبيق رفع الملف الصوتي أو المعالجة الذكية تلقائياً؛ بل لا يحدث ذلك إلا عندما يضغط الطالب الإجراء المقابل.

## البنية التقنية

| الطبقة | التقنية | الغرض |
|---|---|---|
| تطبيق الهاتف | Expo وReact Native وTypeScript | واجهة أصلية تعمل على iOS وAndroid والويب. |
| التخزين المحلي | AsyncStorage ومساحة مستندات التطبيق | حفظ الهيكل الدراسي وبيانات المحاضرات وملفات التسجيل على الجهاز. |
| التسجيل والتشغيل | expo-audio | التقاط الصوت وتشغيله مع واجهة تقدم بسيطة. |
| معالجة الصوت | خدمة تحويل صوت إلى نص على الخادم | تحويل ملف صوتي مناسب إلى نص عربي بعد رفعه عند الطلب. |
| التلخيص | نموذج لغوي على الخادم | إنشاء نتيجة JSON منظمة: نظرة عامة ونقاط ومصطلحات وأسئلة. |
| واجهة الخادم | Express وtRPC | إبقاء أسرار الذكاء الاصطناعي خارج الهاتف والتحقق من الطلبات. |

## التشغيل المحلي

ثبّت الاعتماديات ثم شغّل بيئة التطوير:

```bash
pnpm install
pnpm dev
```

يمكن فتح التطبيق في Expo Go على الهاتف لاختبار الميكروفون الفعلي. أما معاينة الويب فهي مناسبة لمراجعة الواجهات والتنظيم والبحث، لكن رفع تسجيل حقيقي للتحويل إلى نص يتطلب تجربة الهاتف. شغّل الفحوصات البرمجية قبل أي تغيير رئيسي:

```bash
pnpm check
pnpm test
```

## الخصوصية وحدود النسخ الاحتياطي

يعمل التطبيق **محلياً أولاً**. لا تنشئ الميزات حساباً ولا ترفع ملفات تلقائياً. لا يبدأ النسخ الاحتياطي إلا بعد تسجيل دخول صريح واختيار الطالب «إنشاء نسخة احتياطية». تحفظ النسخة الاحتياطية اختيارياً تنظيم الدراسة والنصوص والملخصات وبطاقات المراجعة والمهام، لكنها لا تتضمن التسجيلات الصوتية أو صور السبورة أو المرفقات؛ تبقى هذه الملفات على الجهاز لتقديم حماية خصوصية أعلى وتقليل حجم النقل.

تظهر شاشة إدارة التخزين الحجم المعروف للملفات التي سُجلت بعد هذا التحديث، وتسمح بحذف المحاضرة وملفاتها المحلية. أما السجلات الأقدم التي لم تحفظ حجم الملف، فيظهر حجمها صفراً حتى يُعاد تسجيلها أو تُنشأ مرفقات جديدة.

## خارطة التطوير التالية

| الأولوية | التحسين | القيمة للطالب |
|---|---|---|
| مرتفعة | تقسيم المحاضرات الطويلة وإعادة دمج النص | لا يزال التحويل يحد حجم الملف الصوتي؛ يلزم ترميز صوتي محلي أو خادم معالجة مختص للتقسيم الحقيقي. |
| متوسطة | نسخ احتياطي للملفات الصوتية والمرفقات | النسخة الحالية تحمي خصوصية الملفات بإبقائها محلية، ويمكن إضافة تخزين مشفر اختياري لاحقاً. |
| متوسطة | اختيار التاريخ والوقت برسوم أصلية | يستعمل منشئ المهام حالياً صيغة تاريخ نصية واضحة لتجنب اعتماد واجهة خارجية. |
| لاحقة | مشاركة تعاونية مقيدة بالصلاحيات | المشاركة الحالية تصدّر PDF يختاره الطالب؛ يمكن إضافة رابط قراءة مؤقت لمجموعة دراسية لاحقاً. |

## ملفات التخطيط

تحتوي الملفات التالية على تفاصيل التصميم والتنفيذ:

| الملف | المحتوى |
|---|---|
| `design.md` | تصميم الواجهات، التدفقات، ألوان الهوية، وقواعد الوصول. |
| `implementation-plan.md` | نموذج البيانات، بدائل الحفظ، مراحل الذكاء الاصطناعي، وخارطة التنفيذ. |
| `expansion-design.md` | قرارات التوسعة المحلية أولاً، وتدفقات المرفقات والمراجعة والنسخ الاختياري. |
| `todo.md` | سجل الأعمال المنجزة والمتبقية للمشروع. |

## الاختبارات المنفذة

تتحقق اختبارات الوحدة من تنشيط السنة الجديدة، وعدم تكرار الترم، وصحة الفصل بين النظري والعملي، وتهريب النص عند إنشاء ملف PDF، وعدم إدراج مسارات الصوت والمرفقات المحلية في النسخة الاختيارية. تمرّ الاختبارات باستخدام `pnpm test`، كما يمر فحص الأنواع باستخدام `pnpm check`.
